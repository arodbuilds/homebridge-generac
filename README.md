# Generac for Homebridge

`homebridge-generac` shows the standby generators on your Generac Mobile Link account in the Home app. Each generator appears as a Running sensor, a Fault sensor, a Maintenance Due sensor and a starting battery reading, so you can see at a glance whether the unit is ready, get notified when it starts, and automate around it. It is read only and never stores your Mobile Link password. Not affiliated with Generac.

Documentation arrives with the first beta. Until then, SPEC.md describes the plugin, the settings page and the sensors, and CHANGELOG.md lists what each build adds.
